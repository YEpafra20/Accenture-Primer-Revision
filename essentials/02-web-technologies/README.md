## Key Takeaways

- Web technology is the communication layer between devices, browsers, and servers using markup languages like HTML.
- Frontend development (HTML, CSS, JavaScript) is what the user directly interacts with; backend development (Java, PHP, Python, Node.js) powers the server side.
- Static pages always return the same pre-built content; dynamic pages generate content on the fly using client-side and/or server-side scripting.
- JavaScript can run on both the client (browser) and server (Node.js), and drives user events, business logic, and dynamic content.
- The DOM represents every element of a web page as an object that JavaScript can read and manipulate.
- jQuery simplifies DOM manipulation, event handling, and effects compared to plain JavaScript.
- Good quality code is judged by four pillars: Robustness, Portability, Maintainability, and Readability.
