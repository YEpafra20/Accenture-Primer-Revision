## Key Takeaways

- Algorithms and flowcharts are the foundation of logic building before writing any code.
- Control structures (selection, looping) and arrays are the core building blocks of program logic.
- SDLC provides a structured, repeatable process to convert user needs into working software.
- Every software process model (Waterfall, V-Model, Prototype, RAD, Incremental, Spiral) fits a different project risk/requirement profile.
- Testing is not just "finding bugs" — it is Verification (build it right) + Validation (build the right thing).
- Software Configuration Management (SCM) keeps changes traceable, controlled, and auditable across the software's lifecycle.
